{hygiene_section}

Before making a decision, read the originals; do not judge something to be a duplicate based solely on similarity. Retain customer- and project-specific details, sources, `[IMPORTANT]` rules, and original records. If uncertain, make no changes and report it as a suggestion. Do not perform IDENTITY.md, SOUL.md, AGENTS.md, permissions, rewrite original episodes, or scan or compress the entire memory library.

Update or archive only verified duplicate knowledge and outdated procedures, and clearly state which original text you retained and why. There is no need to create concepts just to meet a count. Do not delegate maintenance tasks or send messages.

Briefly report changes and unresolved contradictions. No changes is also a valid outcome.
