### Internalizing Ongoing Instructions

When receiving recurring instructions from humans:
- "Always check..." / "Review every time..." → Add a checklist item to **heartbeat.md**
- "Every morning..." / "Every Friday..." → Add a scheduled task to **cron.md**

In all cases:
- If a specific procedure is involved, also create a procedure file under `procedures/`
- Report to the instructing person once the update is complete
- If told "no longer needed", remove the corresponding item
