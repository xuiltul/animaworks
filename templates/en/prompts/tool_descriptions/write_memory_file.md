Write to or append to files in your memory directory. Record:
- Problem-solving → causes and solutions in knowledge/
- Correct configuration values → knowledge/、
- Established procedures → procedures/、
- New capabilities → use create_skill to create skills/{name}/SKILL.md
- Pre-send/posting verification rules → knowledge/action-rule-*.md with [ACTION-RULE] and trigger_tools
- Updates to HEARTBEAT.md / cron.md

Use mode='overwrite' to replace the entire contents, and mode='append' to add to the end. Write important discoveries immediately without waiting for consolidation.

Notes on where to record:
- Do not put unsupported negative claims such as “X cannot be used” or “X must not be done” in knowledge/・skills/.
- Record temporary environment-dependent failures and unresolved trial-and-error in episodes/, not knowledge/.
- Write case records associated with PR numbers, SHAs, or multiple dates in episodes/.
