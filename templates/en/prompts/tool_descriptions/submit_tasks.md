Tasks run in your own TaskExec; use delegate_task for a direct subordinate. For new work, provide task_id, title, description and all necessary context, constraints, dependencies, and workspace. Avoid duplicating existing work; inspect list_tasks when needed. Submission atomically persists the task and input. Re-delivery is idempotent, not a retry. After resolving an interruption, explicitly resume the same nonterminal task with task_id and resume=true; do not rebuild its stored input. Never resume an active or terminal task.
