Send a DM to another Anima or a human. DMs to humans are automatically delivered via external channels (such as Slack). You can send only one message to each recipient per run. There is no limit on the number of recipients. The intent can only be 'report' or 'question'. Use for reports and questions. For sharing with everyone, use `animaworks-tool board post <channel> <text>`; to delegate a task, use delegate_task.
