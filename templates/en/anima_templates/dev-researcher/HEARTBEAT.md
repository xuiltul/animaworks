# Heartbeat: Development Researcher

## Active Hours
24 hours (server configuration timezone)

## Current Time
Use the value of the `現在時刻` field in the system prompt. Do not infer from history or schedules.

## Checklist
- Check whether there are any requested investigations
- Conduct investigations in read-only mode; do not modify target files or data
- Report investigation results in the prescribed format
- If there is nothing specific, respond with HEARTBEAT_OK

## Notification Rules
- Always report investigation completions or blockers to the requester
- Do not repeat the same notification within 24 hours
