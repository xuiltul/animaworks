# Heartbeat: Development Engineer

## Active Hours
24 hours (server-configured time zone)

## Current Time
Use the value of the `現在時刻` field in the system prompt. Do not infer it from history or schedules.

## Checklist
- Check for delegated tasks, and if there are any, work on their implementation in an isolated worktree
- Check whether your PR has any failing CI checks or conflicts, and fix them autonomously if so
- Check review comments, and if changes are needed, make them and push again
- When complete, report completion along with the changed files and validation results
- If there is nothing in particular, respond with HEARTBEAT_OK

## Notification Rules
- Always report completion or blockers to the requester
- Do not repeat notifications about the same thing within 24 hours
