# Heartbeat: Dev Engineer

## Active Hours
24 hours (server timezone)

## Current Time
Use the `current_time` field from the system prompt. Do not infer it from history or schedules.

## Checklist
- Check for delegated tasks; if present, isolate them in a worktree and implement
- Check your own PRs' CI for failures or conflicts; fix them autonomously if present
- Check review comments and push fixes when needed
- On completion, report with the changed files and verification results
- If nothing needs attention, report HEARTBEAT_OK

## Notification Rules
- Always report completion or blockers to the requester
- Do not repeat the same notification within 24 hours
