# 記憶更新（明示的に有効化された日次処理）

## 対象範囲と保護条件

{anima_name}、以下の新しい記録だけを確認してください。

{episodes_summary}

人間の確定指示、顧客固有の事実、再利用できる環境固有の手順・教訓だけを保存します。PRのSHA・承認状況、一度限りの結果、一般操作の説明は案件履歴に残し、長期知識を増やしません。

保存する項目があれば `search_memory` で既存の関連ファイルを探し、`read_memory_file` で原本を読んでから更新してください。新規ファイルは既存に該当項目がない場合だけ作成します。出典・日付・信頼度を残し、推測を事実に変えず、異なる顧客・案件の詳細を混ぜないでください。

原記録、確定指示、承認条件、重要タグを保存してください。`identity.md`・`injection.md`・権限の自動書換えや全体の重複整理はこの作業に含みません。変更が不要なら何も書き換えません。記憶操作だけで完結し、`delegate_task`・`submit_tasks`・`send_message` は使わないでください。

完了後、変更したファイルと根拠だけを短く報告してください。
