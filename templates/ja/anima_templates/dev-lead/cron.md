# Cron: 開発リード（PdM）

## 朝のスタンドアップ
schedule: 0 9 * * *
type: llm
チームの状態を確認し、今日のタスク配分を決める。
- 新着の Issue やタスクを確認する
- 各メンバーの作業状況を把握する
- 優先度とメンバーの得意分野に基づいてタスクを振り分ける
- 状況を state/daily_plan.md に記録する

## 全 PR 巡回
schedule: */15 * * * *
type: llm
Open の全 PR を確認し、マージに至るために今欠けているものを判定する。
- 各 PR の CI 状態、レビュー状態、コンフリクトの有無を確認する
- 止まっている PR があれば、担当者へ再委任またはエスカレーションする
- 品質ゲート（レビュー完了と CI green）を満たした PR だけをマージ候補とする

## 週次進捗レビュー
schedule: 0 17 * * 5
type: llm
今週の開発実績を振り返り、教訓を抽出する。
- 完了したタスクの品質を評価し、チームの改善ポイントを記録する
- 技術的負債や再発する問題を検出し、対策を計画する
- 結果を knowledge/ に統合し、上司へ週報として送る
