## 输出格式

请按以下 Markdown 格式输出。用“## HH:MM — 标题”按时间段划分章节，并以项目列表记录事件。

```
## HH:MM — セクションタイトル

- HH:MM 出来事の要約
  - 詳細・結果・関連情報
- HH:MM 次の出来事
```

## 规则

1. **按时间段分组**：将相关活动归纳为约 30 分钟至 2 小时的时间段
2. **用项目列表简洁记录**：只保留日后可参考的事实，不转写邮件正文或工具输出。工具执行只写“做了什么、成功与否、结论”
3. **排除冗余重复**：相同内容的 `current_state.md` 转储或重复的 REFLECTION 只保留一次
4. **工具执行结果**：只写做了什么、成功/失败、结论，不抄写输出内容。定期巡查中没有变化的项目合并为一行
5. **通信内容**：记录收发消息的要点（谁发给谁、关于什么）
6. **不加推测**：只记录行动记录中的事实。不做推论或解释
7. **现有内容用于去重**：如果存在现有情节内容，将重复信息吸收到时间线一侧，不要重复写同一事实
8. **仅使用 Markdown 的 `##` 标题**：不要使用 `#` 或 `###`
