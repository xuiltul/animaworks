向自己的记忆目录中的文件写入或追加内容。应当记录的时候：问题解决→在knowledge/中记录原因和解决方案、正确的配置值→knowledge/、确立步骤→procedures/、新能力→用create_skill创建 skills/{name}/SKILL.md、发送・发布前的确认规则→在knowledge/action-rule-*.md中写入[ACTION-RULE]和trigger_tools、更新HEARTBEAT.md / cron.md。mode='overwrite' 为整体替换，mode='append' 为末尾追加。重要发现不要等待consolidation，应立即写入。
记录位置的注意事项：
- 不要将尚未确认依据的“X不能用／不能做”等否定性主张写入knowledge/・skills/。
- 环境依赖的临时失败或未解决的试错不要写入knowledge/，而应留在episodes/中。
- 与PR编号・SHA・多个日期相关的案件记录应写入episodes/。
