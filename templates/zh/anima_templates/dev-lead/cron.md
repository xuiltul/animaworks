# Cron：开发负责人（PdM）

## 早晨站会
schedule: 0 9 * * *
type: llm
确认团队状态，决定今天的任务分配。
- 确认新到的 Issue 和任务
- 掌握各成员的工作状态
- 根据优先级和成员擅长的领域分配任务
- 将状态记录到 state/daily_plan.md 中

## 全 PR 巡查
schedule: */15 * * * *
type: llm
确认所有 Open 的 PR，判定为了达成合并当前缺少什么。
- 确认各 PR 的 CI 状态、评审状态、是否存在冲突
- 如果有停滞的 PR，向负责人重新委派或上报
- 仅将满足质量门禁（评审完成且 CI green）的 PR 作为合并候选

## 周度进度评审
schedule: 0 17 * * 5
type: llm
回顾本周的开发成果，提炼经验教训。
- 评估已完成任务的质量，记录团队的改进点
- 检测技术债务和反复出现的问题，并制定对策
- 将结果整合到 knowledge/ 中，并作为周报发送给上司
