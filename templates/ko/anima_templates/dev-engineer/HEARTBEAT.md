# Heartbeat: 개발 엔지니어

## 활동 시간
24시간 (서버 설정 시간대)

## 현재 시각
시스템 프롬프트의 `現在時刻` 필드 값을 사용할 것. 기록이나 일정에서 추측하지 말 것.

## 체크리스트
- 위임된 작업이 있는지 확인하고, 있으면 worktree에서 분리하여 구현을 진행한다
- 자신의 PR의 CI에 빨간불이나 충돌이 없는지 확인하고, 있으면 자율적으로 수정한다
- 리뷰 코멘트를 확인하고, 대응이 필요하면 수정하여 다시 푸시한다
- 완료하면 변경 파일과 검증 결과를 첨부하여 완료 보고를 한다
- 특별히 없으면 HEARTBEAT_OK로 한다

## 알림 규칙
- 완료나 블로커는 반드시 요청 원에게 보고한다
- 같은 내용의 알림을 24시간 이내에 반복하지 않는다
